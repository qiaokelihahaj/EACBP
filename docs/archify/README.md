## 读图时需要保留的语义

- 图中顺序是概念级抽象。预处理也逐任务执行审计，数据流图将多次审计合并显示；不是只在末端审计一次。AnnData 是多版本派生产物，不是所有分析共用一个可变文件。
- FASTQ 路径先调用实际定量工具，需要参考文件与样本元数据；h5ad 路径直接注册表达输入，不重新比对。
- 科研图主要展示 standard 分析主干。多目标群体共享预处理，各目标有独立 URI、参数与分支内 FDR 范围。空间分析使用完整 annotated 矩阵。
- 差异分析与差异丰度不是同一个任务。缺失或含糊对比会省略自动统计及消费者，显式非法对比会失败；供体不足省略丰度推断。高级差异分析使用 PyDESeq2，可进行 donor 留一敏感性分析。
- DPT 需要明确根细胞；CellRank 还需要终末细胞。命运概率依赖输入模型，不代表这里实现了从 spliced/unspliced 推断 RNA velocity。
- 可选分支还包括功能活性、通讯、知识查询、本地适配器与扰动模拟，按配置和资源启用；为保持主图可读性，未逐一展开。知识源为本地未核验资料，扰动模拟不提供实验因果确认。
- 原子发布发生在审计前。失败产物可保留用于诊断，但不能贡献证据。检查点与持久审计回执完成后才更新证据与计划；恢复复用产物仍须重审。
- 恢复图的“需要新计算”指正常执行路径，不能理解为任何不匹配都自动覆盖旧产物。严格恢复会拒绝不兼容配置或失效输入/输出；必要时需使用新运行目录。
- 置信度是启发式摘要，不是校准概率。报告从已持久化、经完整性复核的证据快照重建。

## 文件与验证

HTML 可独立打开，支持明暗主题、缩放、搜索、关系追踪与导出。JSON 是可维护的图表源。`*.delivery.json` 保存规范与 HTML 的 SHA-256 和字节数；`*.visual-check.json` 保存浏览器检查结果。`handoff.json` 汇总交付与实际截图审阅状态，自动检查自身的 visualReview=pending 不代表人工视觉审阅结果。

浏览器检查覆盖 1440×900、1600×1000、1920×1080、2048×1320；实际查看了各图 1440×900 深色和 2048×1320 浅色截图。默认阅读态的内容、连线与标签通过视觉审阅；未逐一操作搜索、焦点或所有导出格式。

P4 新增统一证据准入、执行策略、应用服务与研究包，细节见 [架构改进说明](../../ARCHITECTURE_P4.md)。科研与恢复图保持概念主干；Python 进程内任务只在边界检查时间/取消，外部进程运行中受监督。
