从第一次分析开始
新手帮助

    

    

      
先看看你手里有什么

      
一个 .h5ad 文件
里面通常同时保存基因表达和细胞信息。点击“选择文件”，系统会读取可用信息；是否包含完整实验记录仍需核对。
两份 CSV / TSV 表格
需要一份原始计数矩阵和一份细胞信息表。细胞 ID 必须一致，矩阵里应是原始的非负整数计数。
FASTQ、10x 原始文件或只有一张结果表
需要先请数据提供者整理成可用输入。结果图、差异基因表和经过标准化的表达表不能直接替代原始计数矩阵。

      

      
还没有合适数据？复制这份清单给数据提供者

    

    

      
把数据里的列名，对应到实验记录
下拉框里的列名可以不同，关键是列中记录的含义。请结合实验记录确认。

      
实验分组 → condition / group 等列
记录细胞来自哪一组，例如健康或疾病、治疗前或治疗后。
独立样本 → donor / patient_id 等列
记录来自哪位患者、哪只动物或哪个独立生物学重复。来自同一患者的 1,000 个细胞，仍只算 1 个独立重复。
实验批次 → batch 等列
记录哪次实验或哪个处理批次。批次与健康/疾病分组是两种信息，应按实验记录分别填写。
样本编号 → sample_id 等列
用于显示样本数量。同一患者的不同取样或技术重复，不能自动算成不同独立重复。

      
看一个“4 个细胞来自 2 位患者”的例子
细胞 IDgroup：分组patient_id：患者sample_id：取样
cell_01治疗前患者甲甲_治疗前
cell_02治疗前患者甲甲_治疗前
cell_03治疗后患者甲甲_治疗后
cell_04治疗前患者乙乙_治疗前
示意数据：选 group 作分组、patient_id 作独立样本。甲出现在治疗前和治疗后，提示要按真实实验确认配对；乙缺少治疗后观测，且独立重复不足，这份示例不能直接用于配对推断。

      
不确定某列的含义时，先向数据提供者核实。页面提示的候选列需要你确认后才会采用。

    

    

      
完成后，按这个顺序看结果
  1. 先看数据质量
    检查保留了多少细胞、过滤原因和质量提醒，再结合组织与实验判断是否合理。
  2. 再看细胞分群与组成
    图上的每个点代表一个细胞。分群及二维位置提供探索线索，细胞类型需要结合标签或标志基因核对。
  3. 最后看组间比较与报告
    核对研究组/参照组方向、独立重复和统计提醒。差异基因是进一步验证的候选，不能仅凭显著性确定机制。
结果页会说明哪些结果可用。没有展示的步骤，请先查看任务状态和报告中的原因。

这两份表应该长什么样？
下面以“行是细胞、列是基因”为例；首列保存 ID，第一行保存列名。实际文件需包含全部细胞，两份表的细胞 ID 集合必须一致。
原始计数矩阵（counts.csv）
cell_id,gene_A,gene_B
cell_01,0,3
cell_02,2,1
细胞信息表（metadata.csv）
cell_id,group,patient_id
cell_01,control,患者甲
cell_02,treated,患者乙
仅展示文件格式。这两个细胞不足以支持可靠的组间推断；独立重复要按真实患者或动物记录。
